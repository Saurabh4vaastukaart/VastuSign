# VastuSign visual language

VastuSign uses a modern Indian premium aesthetic without copying the reference
application or turning every surface into decorative artwork.

## Palette

- Midnight navy: trust, depth, report covers, compass surfaces
- Warm ivory: readable application and PDF backgrounds
- Antique gold: brand, direction markers, premium actions
- Emerald: confident and supportive observations
- Amber: review and boundary uncertainty
- Coral: critical observations and destructive actions

## Interaction principles

- One primary action per screen
- Calibration quality is always visible during measurement
- A direction is never presented as certain when sensor accuracy overlaps a boundary
- Effects and remedies are progressively disclosed rather than repeated across pages
- Payment and product recommendations never interrupt the core analysis
- English and Devanagari layouts use fonts with complete glyph coverage

## Report design

The PDF will normally fit nine observations in 14-18 pages instead of repeating
three pages for each room. The in-app report uses expandable observation cards,
while the A4 version uses automatic page breaking and one flexible observation
component per room.
